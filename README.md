基于STM32F103标准库实现的串口不定长数据接收函数，包括了两种不同的写法：
# 标准库的阻塞轮巡函数（**不定长数据接收**）
注意这里要使用systick，作为超时判断；
注意要将IDLE和RXNE分开判断，否则读DR，注意这里下一位的数据会从移位寄存器搬运进DR，目前的数据就会丢失，必须保证IDLE是数据接受完成。

# 标准库 串口ILDE+DMA非阻塞（不定长数据）
## 串口+DMA 接收不定长数据，必须开 IDLE 中断；RXNE 中断可以不开。
## 注意，涉及中断的rx_len、rx_buf加上volatile
普通串口**RXNE 中断**接收中断：每接收一个字节都会触发一次，CPU被频繁打断。
DMA+IDLE空闲中断，当 RX 线上连续一段时间没有新数据，也就是总线从“有数据”变成“空闲”，硬件就会置位 IDLE 标志，触发空闲中断，适合数据量大、波特率高、对 CPU 占用敏感的场景。
